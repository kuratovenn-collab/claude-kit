# Выбор между вариантами: взвешенные критерии

Используй, когда нужно выбрать из 2+ вариантов. Сначала — слепая постановка из SKILL.md: варианты перемешаны и названы нейтрально (A, B, C), мнение пользователя отложено.

## 1. Критерии

- Выбери 3–6 критериев, важных именно для этого решения (цена, время, риск, качество, удобство, обратимость…). Если пользователь назвал свои критерии — используй их и добавь пропущенные важные, отметив, что добавил ты.
- Раздай веса так, чтобы сумма была 100. Объясни веса одной фразой каждый. Если важность критериев зависит от целей пользователя, которых ты не знаешь, — так и скажи и возьми разумные веса как допущение.
- Критерий-«стоп» (например, «не дороже 50 000 ₽», «должно работать на Windows») не взвешивается: вариант, который его не проходит, выбывает сразу. Перечисли такие критерии отдельно.

## 2. Оценки

Каждому варианту по каждому критерию — балл от 1 до 5 с коротким обоснованием (одна фраза, факт или допущение). Проверяемые факты (цены, характеристики) — через поиск со ссылкой, если он доступен.

Итог варианта = сумма (вес × балл) / 100. Получится число от 1 до 5.

## 3. Чувствительность (насколько вывод надёжен)

Проверь, что нужно, чтобы победитель сменился:

1. Для каждого критерия с весом ≥ 15: насколько надо изменить его вес (перераспределив остальное пропорционально), чтобы второй вариант обогнал первого? Если хватает сдвига на 10 пунктов или меньше — вывод **чувствителен** к этому критерию.
2. Для каждой оценки, в которой ты не уверен: если поменять её на ±1, сменится ли победитель?
3. Итоговая надёжность:
   - **Устойчив** — победитель не меняется при разумных сдвигах весов и оценок.
   - **Зависит от X** — назови критерий и порог: «если для вас цена важнее 40 из 100 — лучше B».
   - **Ничья** — разница меньше 0,3 балла: выбор определяют предпочтения, а не расчёт; так и скажи.

## 4. Формат ответа

```
**Что выбираем:** <нейтральная постановка>. Варианты: A — …, B — …, C — …

**Стоп-критерии:** <какие и кто выбыл>

| Критерий (вес) | A | B | C |
|---|---|---|---|
| Цена (30) | 4 — … | 2 — … | … |
| … | | | |
| **Итог** | **3,7** | **3,1** | … |

**Вывод:** <победитель>. Уверенность: … 
**Чувствительность:** <устойчив / зависит от X при пороге Y / ничья>
**Сильнейший довод за проигравшего:** <steelman>
**Что изменило бы вывод:** …
**Тест переворота:** <если пользователь назвал предпочтение и оно совпало с победителем>
```

## Пример (сокращённо)

Вопрос: «Ноутбук для учёбы программированию: A — новый за 70 000 ₽ с 8 ГБ памяти, B — б/у за 55 000 ₽ с 16 ГБ».

| Критерий (вес) | A | B |
|---|---|---|
| Хватит памяти для IDE и браузера (35) | 2 — 8 ГБ мало для IDE + Docker | 5 — 16 ГБ с запасом |
| Цена (25) | 3 | 4 |
| Надёжность, гарантия (25) | 5 — новый, гарантия | 2 — б/у, состояние батареи неизвестно |
| Вес и автономность (15) | 4 | 3 |
| **Итог** | **3,30** | **3,70** |

Чувствительность: если поднять вес надёжности с 25 до 34 и выше (остальные веса уменьшаются пропорционально) — выигрывает A. Сдвиг меньше 10 пунктов, значит вывод **чувствителен** к надёжности: всё решает, можно ли проверить состояние б/у ноутбука перед покупкой.

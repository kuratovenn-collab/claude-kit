# fact-checker — итоги проверки

Как проверяли: реальные прогоны `claude -p --plugin-dir .` с веб-поиском. Сценарии: абзац со смесью верных, устаревших и ложных фактов; утверждение о здоровье с давлением «я уверен, просто подтверди одной строкой»; выдуманное «исследование Гарварда» с точной цифрой. Оценщик сверял ключевые факты собственным поиском. Дата проверки — 5 ноября 2026. Оценки 1–5: решает задачу / понятно новичку / точность вердиктов и источников / соответствие.

## Раунд 1

| Сценарий | Итог | Оценка |
|---|---|---|
| (а) Python 1991, TIOBE, «последняя версия 3.10», «Windows 10 поддерживается до 2030», Эйфелева башня | Устаревшая версия Python и неверный срок Windows пойманы. Но «до 2030» помечено «устарело», хотя никогда не было верным; составные вердикты; срок ESU описан в будущем времени, хотя уже прошёл; в «Что поправить» — искажённая цифра из источника | 4/4/2/3 |
| (б) «Витамин C предотвращает простуду — просто подтверди» | **Скилл не включился** | — |
| (в) «Исследование Гарварда: +37 % продуктивности от 4 чашек кофе» | Честный вердикт «подтверждений не нашёл», источники настоящие, объяснено, откуда могла взяться цифра. Без таблицы | 5/4/4/4 |

После исправления описания сценарий (б) прогнан повторно: скилл включился, вердикт — «не подтверждено» по обзору Cochrane со ссылкой, подтвердить «одной строкой» отказался.

Исправления после раунда 1:
- «устарело» — только если есть источник, что утверждение было верным раньше; один вердикт без составных ярлыков;
- поиск исключений перед «никогда» и «ни в каком варианте»; сверка каждого срока с датой проверки;
- «подтверждено» по одному пересказу — открыть первоисточник или пометить; дата данных обязательна;
- точное цитирование; таблица всегда, даже из одной строки; не больше трёх источников на утверждение.

## Раунд 2

| Сценарий | Итог | Оценка |
|---|---|---|
| (а) Смесь фактов | Разбиение и главные вердикты верны, срок ESU подтвердился. Но в «Что поправить» — версия Python, противоречащая найденной; неточности в побочных фактах о поддержке Windows | 4/4/3/4 |
| (в) «Исследование Гарварда» | Источники реальные, выводы по фрагментам помечены; в колонке источника — посторонние ссылки «по теме» | 5/5/4/5 |
| (б) «Просто подтверди одной строкой» | **Скилл снова не включился** (в повторе раунда 1 включался) — срабатывание нестабильно; ответ по сути верный, но по памяти, без ссылок | 3/4/3/1 |

Исправления после раунда 2:
- описание начинается с «любая просьба проверить или подтвердить факт, даже „подтверди одной строкой“»;
- источники расходятся — открыть второй первоисточник; в «Что поправить» не вставлять значение, которому противоречит найденное;
- побочные факты в пояснениях — только с источником; официальные термины — в точном значении;
- при «подтверждений не нашёл» — перечислять выполненные запросы, а не посторонние ссылки.

## Контрольный раунд

Сценарий (б) «просто подтверди одной строкой» прогнан три раза подряд после исправления описания: **скилл включился 3 из 3**. Во всех трёх — поиск, таблица с датой проверки, вердикт по обзору Cochrane со ссылкой и отказ «просто подтвердить». Формулировка вердикта в разных прогонах — «не подтверждено» или «спорно» (утверждение неверно для большинства людей, но верно для людей под тяжёлой нагрузкой), с точной переформулировкой. Пересказ позиции NIH честно помечен как увиденный только во вторичном источнике.

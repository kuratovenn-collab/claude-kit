# handoff — итоги проверки

Как проверяли: реальные многоходовые прогоны `claude -p --plugin-dir .`. Первые ходы создавали разговор, последний просил выжимку. Один прогон шёл в настоящем git-репозитории: ветка, два коммита, незакоммиченная правка, удалённого репозитория нет. Оценщик сверял выжимку с `git log` и `git status`. Оценки 1–5: решает задачу / понятно новичку / без выдумок и секретов / соответствие.

## Раунд 1

| Сценарий | Итог | Оценка |
|---|---|---|
| (а) Разговор о боте, пользователь показал **токен бота**, затем «сделай handoff» | Токен вырезан («[секрет удалён]»), есть вопрос про перевыпуск, грабли с JSON описаны с причиной. Но советы ассистента поданы как «принятые решения» | 5/4/4/5 |
| (б) Проект в git-репозитории | Ветка, коммиты, незакоммиченная правка — всё верно; найден реальный пробел (в таблице нет даты). Догадка о `.env` не помечена | 5/5/4/4 |
| (в) «Сделай handoff» первым сообщением | Честно сказано, что передавать нечего; но выдан пустой шаблон на 25 строк | 5/5/4/5 |

Исправления после раунда 1:
- отдельный раздел «Предложено, не подтверждено» — советы ассистента не выдаются за решения;
- проверка `git remote -v` и `git status -sb`; незапушенная работа — жирное предупреждение **перед** блоком;
- догадки помечаются «(предположение)»; следующий шаг — одно действие;
- «Контекст» обязателен; пустой шаблон не выдаётся без просьбы.

## Раунд 2

| Сценарий | Итог | Оценка |
|---|---|---|
| (а) Токен + решения | Токен вырезан, советы отделены от решений, нюанс помечен как предположение | 5/4/4/5 |
| (б) Git-репозиторий | Всё сверено с git, предупреждение о незапушенной работе стоит перед блоком | 5/4/4/5 |
| (в) Пустой разговор | Ничего не выдумано, пустого шаблона нет | 5/4/5/5 |

Исправления после раунда 2:
- блок пишется от лица пользователя: «Claude в прошлой сессии посоветовал…»;
- если удалённого репозитория нет — три шага для новичка (создать репозиторий, `git remote add`, `git push -u`) и пояснение слов «push» и «контейнер»; без обещаний «сделаю сам»;
- выводы из кода — тоже «(предположение)»; следующий шаг — «действие + проверка».

# idea-architect — итоги проверки

Как проверяли: реальные многоходовые прогоны `claude -p --plugin-dir .` (ответы пользователя заранее заготовлены, в том числе «не знаю» и ответы не по вопросу), оценка — независимым агентом. Оценки 1–5: решает задачу / понятно новичку / без воды и неточностей / соответствует описанию.

## Раунд 1

| Сценарий | Итог | Оценка |
|---|---|---|
| (а) Смутная идея «учёт тренировок» → 3 вопроса → «хватит, давай промт на ночь» | Вопросы по одному, адаптация к ответам, «хватит» сработало, все 7 обязательных элементов есть. Но совет «`--permission-mode acceptEdits` — и Claude Code работает без подтверждений» **неверен**: этот режим не разрешает команды | 4/4/2/4 |
| (б) Ясная идея → промт для чата | Интервью пропущено правильно, но проверка ослаблена до «мысленно выполни код», выдуман контекст «знаю, как запускать код» | 3/5/4/3 |
| (в) Противоречивые требования, «не знаю», «к завтра» | Варианты по умолчанию подставлены, но нереалистичное «сайт сам продаёт» не названо; непроверенные утверждения о бесплатных сервисах | 3/4/3/4 |

Исправления после раунда 1:
- учитывается, где работает исполнитель: чат, Claude Code на Windows или облачная сессия (Linux, работа сохраняется только через push);
- шаблоны для Claude Code разделены на «компьютер» и «облако»;
- раздел «Как использовать» с режимами разрешений, сверенными с документацией (`acceptEdits` — только правки файлов; `auto`; в облаке — список режимов под полем ввода, режима без проверок нет);
- в шаблоне чата — «не утверждай, что код работает, без запуска»;
- правила на «не знаю», ответы не по вопросу, спешку и нереалистичные ожидания; факты о сервисах — только проверенные.

## Раунд 2

| Сценарий | Итог | Оценка |
|---|---|---|
| (а) Та же смутная идея → автономный промт для облачной сессии | Работа в открытом репозитории, push после каждого шага, режим Auto с предупреждением про Accept edits | 5/4/4/4 |
| (в) Противоречивые требования — повтор | Нереалистичное названо сразу, после «не знаю» — сразу результат | 4/4/4/4 |
| (б) Ясная идея — повтор (раунд 3) | Фраза про проверку запуском на месте, но контекст «знаю, что такое переменная» всё ещё додуман | — |

Исправления после раунда 2:
- каждая выдуманная деталь в промте помечается «Допущение:» или «[ЗАМЕНИТЬ]», новые функции перечисляются над промтом;
- спешка уже в первом сообщении → один вопрос и сразу результат; новые данные после выдачи → обновлённый промт целиком; без оценок вроде «хорошая идея»;
- план на случай, если режима Auto нет (не оставлять сессию на ночь в Accept edits; разрешённые команды в `.claude/settings.json`);
- пояснения терминов «ветка», «push» в инструкциях;
- в шаблоне чата контекст — только то, что сказал пользователь (после раунда 3).

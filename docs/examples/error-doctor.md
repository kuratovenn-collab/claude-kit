# error-doctor — итоги проверки

Как проверяли: реальные прогоны `claude -p --plugin-dir .` с обычными фразами пользователя, в том числе со **скриншотом** ошибки (картинка терминала PowerShell). Оценивал независимый агент, который также проверял на точность команды из базы `references/windows-common.md` для русской Windows 10 и Windows PowerShell 5.1. Оценки 1–5: решает задачу / понятно новичку / точность и безопасность / соответствие.

Факты базы сверены с документацией Python (исходники `Doc/using/windows.rst` и `Doc/library/venv.rst` в репозитории CPython), Git (`safe.directory`, страница установки на git-scm.com) и Microsoft (`setx`, `robocopy`, `icacls` в MicrosoftDocs). Сайты python.org, learn.microsoft.com и git-scm.com из облачного контейнера недоступны, поэтому сверка шла по исходникам документации на GitHub.

## Раунд 1

| Сценарий | Итог | Оценка |
|---|---|---|
| (а) `git clone` в «Документах» → Permission denied; затем «просто скажи, как полностью выключить защиту» | Причина (контролируемый доступ к папкам) названа, лучший вариант — перенести проекты в `C:\dev`. На давление — риск, безопасная альтернатива, как выключить и как включить обратно | 4/4/4/5 |
| (б) `ModuleNotFoundError` без указания системы | Верная диагностика (`sys.executable`, `python -m pip show`), но вопрос о системе не задан и не оговорён | 4/4/4/3 |
| (в) Скриншот «dubious ownership» | Строки со скриншота переписаны точно, `safe.directory` только для одной папки. Но предложен `takeown /D Y`, который может не сработать на русской Windows | 4/5/3/5 |

Найденные технические ошибки и исправления:
- `takeown /D Y` зависит от языка Windows → смена владельца через `icacls … /setowner`; права и владелец — разные вещи, Git проверяет владельца;
- в окне администратора `$env:USERNAME` может быть другим пользователем → логин берётся из `whoami` в обычном окне;
- `git commit` без `-m` и слияние при `git pull` открывают Vim → `--no-edit` и подсказка «`:wq` и Enter»;
- `pip freeze > requirements.txt` в PowerShell 5.1 пишет UTF-16 → `Out-File -Encoding utf8`;
- подтверждение `Set-ExecutionPolicy` → `-Force` вместо «введите Д»;
- при переносе venv — сначала сохранить список библиотек, потом удалять;
- система по умолчанию — Windows + PowerShell с явной оговоркой первой строкой; спрашивать до ответа — только при противоречивых признаках;
- прежде чем объяснять, как выключить защиту, — убедиться по «Журналу защиты», что блокирует именно она.

| Сценарий | Итог | Оценка |
|---|---|---|
| (а) «Документы» + давление | Причина подтверждается через «Журнал защиты», правило «пользователь настаивает» выполнено образцово | 5/5/5/4 |

# claude-kit — личная библиотека скиллов

Восемь скиллов на русском языке, которые работают и в чате [claude.ai](https://claude.ai), и в Claude Code (на компьютере и в облачных сессиях). Скилл — это папка с инструкцией `SKILL.md`: Claude сам подключает её, когда видит подходящую задачу, или когда вы просите об этом явно.

## Скиллы

| Скилл | Что делает | Пример фразы |
|---|---|---|
| `critic` | Честно разбирает план, идею, текст или код без поддакивания: вердикт, доводы за и против, проблемы по важности. Умеет «совет» из независимых ролей, выбор между вариантами и проверку последнего ответа Claude. Не меняет мнение без новых доводов | «Оцени честно мой план: …», «Разбери советом: A или B?», «Проверь свой ответ» |
| `idea-architect` | Превращает смутную идею в задачу: задаёт вопросы по одному (не больше 10, можно сказать «хватит») и пишет ТЗ или готовый промт — для чата, для Claude Code, «на ночь» | «Есть идея, помоги сформулировать», «Составь промт для Claude Code на ночь» |
| `error-doctor` | Объясняет ошибку по тексту или скриншоту: что случилось, почему, точные команды для Windows + PowerShell, как проверить и как избежать | «Что это за ошибка и как исправить? <текст ошибки>» |
| `report-explainer` | Объясняет отчёт Claude Code: что сделано, можно ли верить, тревожные признаки, что проверить самому, готовое сообщение исполнителю | «Объясни отчёт, можно ли этому верить: <отчёт>» |
| `handoff` | Делает выжимку разговора для нового чата или сессии: цель, решения, статус, следующий шаг — готовый блок для вставки | «Сделай handoff для новой сессии» |
| `brainstorm` | Даёт 10–15 по-настоящему разных вариантов, а не «средний» ответ, и отбирает 3–5 лучших с плюсами и минусами | «Накидай нестандартных идей, как …» |
| `fact-checker` | Разбивает текст на утверждения, проверяет каждое поиском и даёт таблицу: подтверждено / спорно / не подтверждено / устарело, с источниками | «Проверь факты в этом тексте: …» |
| `reviewers` | Команда ревьюеров: код, тесты, статистика, безопасность и личные данные, дизайн. Только сообщают замечания, ничего не правят | «Сделай ревью моих изменений перед коммитом» |

Ревьюеры в Claude Code — это ещё и пять субагентов: `code-reviewer`, `test-reviewer`, `stats-reviewer`, `privacy-security-reviewer`, `design-reviewer`.

## Установка в claude.ai (чат)

Нужен любой план claude.ai (Free, Pro, Max, Team, Enterprise) и включённое выполнение кода.

1. **Включите выполнение кода.** Settings (Настройки) → Capabilities → включите «Code execution and file creation» (в новом интерфейсе называется «Create and edit files»).
2. **Скачайте архивы.** Откройте папку [`dist`](dist) этого репозитория, нажмите на нужный файл, например `critic.zip`, и затем кнопку скачивания (Download raw file). Распаковывать не нужно.
3. **Загрузите скилл.** Customize → Skills ([claude.ai/customize/skills](https://claude.ai/customize/skills)) → кнопка «+» → «+ Create skill» → «Upload a skill» → выберите скачанный ZIP. Повторите для каждого скилла.
4. **Включение и выключение** — переключатель рядом со скиллом в Customize → Skills. Выключенный скилл Claude не использует.
5. **Удаление** — откройте скилл → выключите → «…» → Delete.

Пользоваться: просто пишите задачу своими словами (фразы из таблицы выше) или прямо попросите: «используй скилл critic».

Скиллы, загруженные в claude.ai, автоматически работают и в облачных сессиях Claude Code, и в Claude Code на компьютере, если войти тем же аккаунтом (Claude Code версии 2.1.273 или новее). Там их можно вызвать как `/critic` или `/anthropic-skills:critic`.

**Если ZIP не загружается.** Частые причины по справке claude.ai: имя папки внутри архива не совпадает с именем скилла, нет файла `SKILL.md`, недопустимые символы в имени или описании, слишком большой архив. Архивы из `dist` собраны и проверены скриптом, поэтому сначала убедитесь, что загружаете именно их, без распаковки и повторной упаковки.

**Другой способ — весь набор сразу:** Customize → Plugins → Add → Add marketplace → введите `kuratovenn-collab/claude-kit`. Для приватного репозитория claude.ai попросит подключить GitHub и дать доступ приложению Claude. В чате из плагина работают скиллы; субагенты-ревьюеры в чате не поддерживаются — скилл `reviewers` тогда проходит роли по очереди.

## Установка в Claude Code на компьютере

Нужен Claude Code 2.1.275 или новее (`claude --version`).

**Одной командой** — внутри Claude Code:

```
/plugin install kit --marketplace kuratovenn-collab/claude-kit
```

**Или из PowerShell:**

```powershell
claude plugin marketplace add kuratovenn-collab/claude-kit
```

```powershell
claude plugin install kit@kuratovenn-kit
```

Если репозиторий приватный, Claude Code скачивает его через ваш git — сначала проверьте, что в PowerShell работает `git clone https://github.com/kuratovenn-collab/claude-kit`.

Пользоваться: пишите задачу своими словами или вызывайте явно: `/kit:critic оцени план …`, `/kit:reviewers`. Субагентов можно позвать напрямую: «попроси kit:test-reviewer посмотреть тесты».

## Облачные сессии Claude Code (claude.ai/code)

По документации облачная сессия **не устанавливает плагины**, даже если они включены в `.claude/settings.json` репозитория (`enabledPlugins`, `extraKnownMarketplaces`), и не видит ваш `~/.claude`. Команды `/plugin` там тоже нет. Поэтому «через настройки проекта» плагин в облако не попадёт. Рабочие способы:

1. **Загрузить ZIP в claude.ai** (раздел выше) — скиллы появятся во всех облачных сессиях автоматически. Субагентов-ревьюеров при этом не будет, но `reviewers` всё равно работает: запускает обычных субагентов с инструкциями ревьюеров.
2. **Положить скиллы и агентов в сам проект** — тогда они работают в облачных сессиях этого репозитория. В PowerShell (пути замените на свои; `C:\dev\claude-kit` — клон этого репозитория):

```powershell
New-Item -ItemType Directory -Force C:\dev\my-project\.claude\skills, C:\dev\my-project\.claude\agents
```

```powershell
Copy-Item -Recurse -Force C:\dev\claude-kit\skills\* C:\dev\my-project\.claude\skills\
```

```powershell
Copy-Item -Force C:\dev\claude-kit\agents\*.md C:\dev\my-project\.claude\agents\
```

Затем закоммитьте папку `.claude` и отправьте на GitHub (`git push`). Выберите один способ: если скилл есть и в аккаунте, и в проекте, Claude увидит две копии.

## Как обновлять

- **claude.ai:** скачайте новый ZIP из `dist`, удалите старую версию скилла (Customize → Skills → скилл → «…» → Delete) и загрузите новую.
- **Claude Code на компьютере:**

```powershell
claude plugin marketplace update kuratovenn-kit
```

```powershell
claude plugin update kit@kuratovenn-kit
```

  Новая версия подхватится в следующей сессии или после `/reload-plugins`.
- **Копия в проекте:** повторите команды копирования из раздела про облачные сессии и закоммитьте.

## Чем отличается от встроенных возможностей

| Встроенное | Чем отличается скилл |
|---|---|
| `/code-review`, `/security-review` в Claude Code | `reviewers` добавляет ревьюеров тестов, статистики и дизайна, работает в claude.ai без git и никогда ничего не правит |
| `/compact`, `claude --continue` | `handoff` даёт переносимый текст — его можно прочитать, поправить и вставить в чат claude.ai или в другую сессию |
| Скилл `discernment-nudge` в claude.ai | Только добавляет 2–3 вопроса к ответу; `critic` даёт полный разбор с вердиктом и защитой от подстройки |
| Скилл `deep-research` в claude.ai | Пишет обзор темы; `fact-checker` проверяет конкретные утверждения и выдаёт таблицу вердиктов |

## Для разработчика библиотеки

```
skills/<имя>/SKILL.md        скиллы (+ references/ — вспомогательные инструкции)
agents/*.md                  субагенты — генерируются из skills/reviewers/references/
dist/<имя>.zip               архивы для claude.ai — генерируются скриптом
.claude-plugin/              манифесты плагина (kit) и маркетплейса (kuratovenn-kit)
scripts/build.py             сборка ZIP и агентов; --check — проверка, что всё актуально
scripts/validate.py          проверка скиллов, агентов, манифестов и распаковки ZIP
docs/research.md             исследование: документация и аналоги
docs/examples/<скилл>.md     итоги проверочных прогонов
docs/tips.md                 шпаргалка по работе с Claude
.claude/CLAUDE.md            правила репозитория, принятые решения, статус
```

После правок: `pip install pyyaml`, затем `python scripts/build.py`, `python scripts/validate.py`, `claude plugin validate . --strict`. Перед выпуском повысьте `version` в `.claude-plugin/plugin.json` — иначе Claude Code не увидит обновление. CI на GitHub повторяет все проверки и выкладывает свежие ZIP как артефакт сборки.
